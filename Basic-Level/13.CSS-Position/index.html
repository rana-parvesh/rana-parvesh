CSS Position Property Examples

This is a statically positioned box. It follows the normal flow of the document.

This is a relatively positioned box. It’s offset 20px from the top and 10px from the left of its original position.

This container has relative positioning to contain the absolute box.

This box is positioned absolutely 50px from the top and 50px from the left within the container.

This box is fixed to the viewport at the top-right corner. It stays here even when scrolling.

This is a sticky positioned box. It will stick to the top of the container when you scroll past it.

Scroll down to see how sticky positioning works. It stays within the flow until the top of the viewport is reached.

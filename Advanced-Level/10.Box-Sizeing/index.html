Understanding box-sizing: content-box vs border-box

content-box (default): Width = 200px, Padding = 20px, Border = 5px

This box has a width of 200px, but the padding and border are added outside the width, making the total width 250px.

border-box: Width = 200px, Padding = 20px, Border = 5px

This box has a width of 200px, with padding and border included inside the width. The total width remains 200px.

Global box-sizing (border-box): Width = 300px, Padding = 40px, Border = 10px

All elements in the page now calculate width using border-box, including this one. The width is fixed at 300px, and padding and border are inside this width.

CSS Overflow Property Tutorial

The overflow property controls how content is handled when it exceeds the dimensions of its container.

Overflow: Visible (default)

This content overflows the container. Since overflow is set to visible, the overflowing part is visible outside the container.

Overflow: Hidden

This content overflows the container. With overflow set to hidden, the overflowing part is cut off, and no scrollbars appear.

Overflow: Scroll

This content overflows the container. With overflow set to scroll, both horizontal and vertical scrollbars appear, allowing you to scroll to see the hidden content.

Overflow: Auto

This content overflows the container. With overflow set to auto, scrollbars appear only if the content overflows. Here, both scrollbars will appear as the content exceeds the container.

Advanced: Overflow-X and Overflow-Y

You can also control overflow for horizontal (X-axis) and vertical (Y-axis) directions separately using overflow-x and overflow-y properties.

This container has overflow-x set to auto and overflow-y set to hidden. A horizontal scrollbar appears, but the vertical overflow is hidden.
